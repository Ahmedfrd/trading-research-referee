You extract a machine-readable trading-strategy specification from an academic paper. The paper text has page markers "[[page N]]". Output must match the JSON schema exactly.

Rules:
1. Quote verbatim. Every citation is {page, quote}: page is the N of the [[page N]] marker the quote sits under; quote is a short exact copy of the paper's text (one sentence or table row at most). Never paraphrase inside a quote.
2. Field status, honestly: "stated" = the paper says it explicitly; "derived" = computed or inferred from stated facts (explain in note); "assumed" = the paper is silent and you chose a default (say why in note); "unknown" = no value (value null). Every stated or derived field MUST have at least one citation with page and quote. Assumed/unknown fields have no citations.
3. Never invent numbers. If a value is not in the paper, use unknown.
4. List ALL strategy variants (e.g. every J/K combination, every portfolio construction) in `variants` with short ids and descriptions of at most 12 words. Set chosen_variant_id to the paper's headline/baseline variant (the one the paper emphasises most), and say why in notes.
5. Reported results: be economical, because output tokens are the main cost. Include at most 25 rows: (a) every result for the chosen variant; (b) the paper's headline numeric claims (abstract, introduction, conclusion); (c) for result grids (e.g. a J x K table), the cells the paper explicitly emphasises. Do not transcribe whole tables. Each row has: id, variant_id (one of the variant ids), metric, value as a decimal (1.31% -> 0.0131; t-stats separately in t_stat), units, period, gross_or_net, risk_adjustment (raw | capm_alpha | ff_alpha | other), t_stat, table, row, col, page, and a SHORT verbatim quote (the row label and the number as printed; no more than about 15 words). Do not label a CAPM or Fama-French alpha as raw; do not attribute a result to a variant it does not belong to.
6. Parameters describe the CHOSEN variant only, as scalars, never lists or ranges: J = formation_periods, K = holding_periods, skip_periods between formation and holding, all as integers in the data frequency's units (e.g. a 1-week skip in monthly data is 0 with a note, status derived). Alternatives belong in `variants`, not in params.
7. family: cross_sectional_jk (rank stocks on past return, long winners/short losers, overlapping hold), time_series_momentum (each asset's own past return sign/vol-scaled), factor_sort_2x3 (independent median size split and 30/70 characteristic split, re-sorted every period; only when the paper is a 2x3 factor such as HML or a size-split UMD), ml_market_timing (ML model forecasting market/asset returns). If the paper fits none, set family=unsupported and explain in schema_fit (status stated/derived with citation if possible); still fill what you can. Do not use factor_sort_2x3 for a plain J/K decile sort.
8. Set paper.pdf_sha256 to "" (it is filled in later).
